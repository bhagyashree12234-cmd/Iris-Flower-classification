Iris Flower Classification 🌸

Project Overview

This project uses Machine Learning to classify Iris flowers into three species: Setosa, Versicolor, and Virginica.

Technologies Used

- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Scikit-learn
- Jupyter Notebook

Algorithm

Decision Tree Classifier

Dataset

Iris Dataset containing 150 samples and 4 features:

- Sepal Length
- Sepal Width
- Petal Length
- Petal Width

Model Accuracy

100% on the test dataset (30 samples).

How to Run

1. Install the required Python libraries.
2. Open the Jupyter Notebook.
3. Run all cells.
4. Enter flower measurements to predict the species.
